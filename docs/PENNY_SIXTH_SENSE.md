# PC.4A — Penny's Sixth Sense

Public read-only /api/penny-awareness: weather (NWS hourly forecast), alerts (NWS actual severe/extreme alerts for selected city), news (GDELT source links from selected publishers, USGS significant earthquakes, NASA recent science/space items). Cache for 15 minutes (alerts 5 minutes); no keys, LLM calls, cron or new DB. No arbitrary source URL or visitor location is accepted. Allowlisted US cities, Omaha default (explicitly labeled); sign defaults to Scorpio. Browser preferences are local to each origin; no geolocation or personal profile data. Original daily reflections are entertainment, not predictive advice. General news is a limited headline discovery feed, not exhaustive or independently verified; GDELT is credited and publisher linked, official sources supplement it. Feed failures omit cards, never synthesize facts. Cards expire, severe alerts take priority, visible page only; existing quips remain. User can inspect source links in conversation dialog. No news is submitted to any model. This is on-demand polling, not push alerts or a life-safety system. Party uses canonical production endpoint and must deploy after hub. No secrets or owner-memory changes.
